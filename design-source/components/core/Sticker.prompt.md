One-line: a rotated handwritten roundel — use it where a conventional UI would put an icon or a badge.

```jsx
<Sticker size="lg">be<br />happy</Sticker>
<Sticker tone="turquoise" size="sm" rotate={-6}>do<br />domu</Sticker>
```

Rules: two words maximum, lowercase, no punctuation. Absolutely position it so it overlaps the corner of a photo or card — but check it does not land on type. One sticker per screen region; three on a page is already too many.
